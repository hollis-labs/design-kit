# Theme migration: workflow vocabulary (CW-20260911-0071, split b)

Rendered kit-dashboard theme gallery with design-components and kit-chat, using
headless Chromium at 1440 × 1200. Before: storage split a (3e3508e, merged in
fafc6e7). After: canonical dash-status utilities, unchanged theme bindings.
Ten built-in themes in both modes, plus the four supported legacy dark IDs.
Motion, transitions and caret are frozen for endpoint comparison.

All 24 screenshot pairs are byte-identical. All sampled base/kit palette values
and rendered text, background, border, font size and weight are exactly equal;
no browser page errors. The compact before.json/after.json hold those measurements.
No palette redesign or feedback-severity migration is included in this split.
